# Tarea 4 - Teoría de la Complejidad

Proyecto desarrollado en Java para evaluar algoritmos de búsqueda, ordenamiento y complejidad algorítmica.

## Archivos

- `Main.java`
- `MatrizAleatoria.java`
- `Busquedas.java`
- `Ordenamientos.java`
- `MedicionTiempo.java`
- `DetectorSobrecorriente.java`

## Requisitos

Tener Java instalado. Se puede verificar con:

```bash
java -version
```

## Ejecución

Abrir una terminal en la carpeta del proyecto y compilar:

```bash
javac *.java
```

Ejecutar el programa:

```bash
java Main
```

## Nota

Los archivos `.class` no se suben al repositorio porque se generan al compilar el proyecto.
